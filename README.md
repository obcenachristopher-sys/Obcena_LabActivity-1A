## Laboratory Discussion

To integrate the post image into `newsfeed_card.dart` and make it dynamic depending on whether a post contains an image, I first created a reusable `PostImageWidget` in `lib/widgets/post_image_widget.dart` that renders an asset image (`Image.asset`) wrapped with rounded corners (`ClipRRect` and `borderRadius.r`) and responsive sizing via `flutter_screenutil`. Next, I imported `package:obcena_mobprog/widgets/post_image_widget.dart` into `lib/widgets/newsfeed_card.dart` and used the `hasImage` boolean property (`bool? hasImage`) passed to `NewsfeedCard` to conditionally display the image inside the post's vertical `Column` layout. Specifically, I used a ternary expression (`widget.hasImage == true ? const PostImageWidget(...) : const SizedBox.shrink()`) right below the post content text so that posts with `hasImage: true` render `PostImageWidget` cleanly without cropping, while posts where `hasImage` is `false` or `null` render `SizedBox.shrink()` and take up no extra vertical space.
